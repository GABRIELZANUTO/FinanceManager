Formato do arquivo

Uma linha de cabeçalho com estas colunas:

date,type,name,category,amount,payee,account,tags,note

  • date (data): AAAA-MM-DD ou DD/MM/AAAA
  • type (tipo): income/receita ou expense/despesa
  • amount (valor): positivo, com até duas casas decimais (1234.56 ou 1.234,56)
  • name (descrição) é obrigatório; category (categoria) pode ficar vazia quando uma regra de categorização combinar com a descrição ou o favorecido
  • categorias desconhecidas são criadas automaticamente; a conta (account) precisa já existir (vazia usa a primeira conta)
  • tags são separadas por ponto e vírgula
  • payee é o favorecido e note é a observação
  • o arquivo gerado por Exportar CSV pode ser importado sem alterações; use ponto e vírgula como separador de colunas se os valores tiverem vírgula decimal
